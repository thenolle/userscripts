## Install

1. Install a userscript manager: [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open the **Install** button on the overview page and confirm in your manager.
3. Open perplexity.ai and sign in.

Updates arrive through your manager, and the script also checks for new versions about every 12 hours.

## Take the tour

Click the **?** button in the header for guided tours. Each tour highlights real buttons and asks you to click or press the keys it describes.

## Where things are

| Where               | What                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| Header badge        | Remaining queries for the selected mode; hover for a summary, click for details |
| Header buttons      | Export, settings and the tutorial                                               |
| Message box buttons | Enter-as-newline settings, big messages, prompt library, batch runner           |
| Select any text     | A toolbar to ask, explain, summarize, fact-check or quote it                    |

## Turn modules on and off

Open the settings dialog (the sliders button). Every feature is a module with its own switch and its own settings. Disabled modules stay completely idle.

> [!NOTE]
> The header buttons attach to the usage badge. If you disable **Usage Quota V2**, those buttons disappear, but every action is still in the command palette.
