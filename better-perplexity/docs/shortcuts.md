## Default shortcuts

| Action                          | Shortcut                        |
| ------------------------------- | ------------------------------- |
| Command palette                 | `Alt + Shift + P`               |
| Prompt library                  | `Alt + Shift + L`               |
| Send a message                  | `Ctrl + Enter` or `Cmd + Enter` |
| New line                        | `Enter`                         |
| Run a selection action and send | Shift-click the action          |

Change them from the userscript menu or the settings dialog.

## Enter as newline

Enter inserts a new line and a shortcut you choose sends the message. Click the keyboard button next to the message box to pick which modifier combinations send.

## Command palette

Search every action from the keyboard: modules, dialogs, export, scrolling, copying the URL and more. Arrow keys move, Enter runs, Escape closes.

## Selection toolbar

Select text in an answer to ask a question about it, have it explained or summarized, fact-check it, or quote it into the message box.

## Layout

**Max Width** removes width limits so answers use the whole window. The right sidebar can be removed separately from the menu.
