# Getting help

- **How do I use it?** Open the “?” button in the Perplexity header for an interactive tour.
- **Something is broken:** open a [bug report](https://github.com/thenolle/userscripts/issues/new?template=bug_report.yml) with your script version, browser and userscript manager.
- **An idea:** open a [feature request](https://github.com/thenolle/userscripts/issues/new?template=feature_request.yml).
- **A prompt for the community library:** use the [prompt submission](https://github.com/thenolle/userscripts/issues/new?template=prompt_submission.yml) form.
- **Security:** see [SECURITY.md](SECURITY.md).
