# Security policy

## Supported versions

Only the latest published version of each userscript receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use [private vulnerability reporting](https://github.com/thenolle/userscripts/security/advisories/new) on this repository. Include the script, version, steps to reproduce and impact.

You can expect an acknowledgement within 7 days and a status update within 30 days.

## What the scripts do with your data

Better Perplexity makes requests only to Perplexity (your own account's pages and APIs, from your browser session) and to `raw.githubusercontent.com` for update checks and community prompts. It has no analytics and sends nothing to any server of its own.
